XDownloader 1.4.0 兼容性说明
制作人：Peror0_sama

本兼容版本由 AI 辅助完成，保留原版的下载、登录、队列、报告和托盘功能。
兼容修改不影响 Windows x64 原版。各平台的登录信息和数据目录独立，不应复制账号数据。
需要能够访问 X 及媒体服务器的网络。只能下载当前访问方式有权查看的内容。

第三方组件
原有 THIRD_PARTY_NOTICES.txt 保留项目历史说明；本文件列明兼容版实际替换的组件。
第三方组件继续适用各自许可证，不附加本项目的非商业限制。

运行环境
Windows 10 x86（32 位），也可在支持 32 位程序的 Windows x64 上运行。
完整解压后双击 XDownloader.exe。Python、Qt、网页运行时和 FFmpeg 已内嵌，无需另装。
下载位置默认是程序同级 download 文件夹，可在应用内修改。

兼容组件
Python 3.10.11；PySide2 / Qt 5.15.2.1；Pillow 11.3.0。
WebView2 Fixed Runtime 157.0.4341.60 x86；独立宿主为 .NET 10.0.15 win-x86。
FFmpeg 8.1.2 为 x86 静态构建，采用 LGPL 2.1 或更新版本，源码为 https://ffmpeg.org/releases/ffmpeg-8.1.2.tar.xz。
FFmpeg 用于本地 GIF 转换和广播分段合并，构建脚本及许可证见 third_party/ffmpeg。
PySide2 / Qt 采用 LGPL v3 许可选项；对应许可证见 third_party/licenses。
WebView2 x86 官方运行时包含 dual_engine_adapter_x64.dll 辅助文件，按官方原包保留。

验证情况
1.4.0 在 Windows x64 的 32 位运行环境中通过暂停、恢复、失败分类及相关源码回归测试。
旧版已验证原生 Qt 初始化、错误插件环境变量隔离、H.264/AAC 播放、GIF 转换和本地 HLS 合并。
尚未在原生 32 位 Windows 电脑完成实测；1.4.0 EXE 主界面和真实账号登录仍待手动验证。
