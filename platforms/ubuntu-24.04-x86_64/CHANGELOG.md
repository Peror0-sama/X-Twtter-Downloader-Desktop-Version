# 版本更新记录

当前版本：**1.3.6**。制作人：**Peror0_sama**。

## 1.3.6

### 修复

- 修复了内嵌网页无法输入的问题。
- 修复 Windows 无控制台打包程序使用 `--help` 时的输出流异常。

## 1.3.5

### 新增

- 将上一版登录网址栏锁定修订正式更新为 1.3.5；窗口标题、版本标识和发布包同步。
- 沿用 1.3.4 登录网址栏锁定修复，无功能变更。
- 提供单独可运行的 Windows x64 ZIP，文件校验清单放在 ZIP 内。

## 1.3.4

### 新增

- 作者、推文计划和媒体文件行显示下载进度条，折叠作者后仍可看到汇总进度。
- 普通文件按字节显示，广播按已完成分段显示；多文件按各文件进度汇总。
- 总量未知时显示条纹和已下载大小；合并、转换、校验阶段最高 99%，保存成功后才到 100%。

### 修复与同版本修订

- 调整进度列与名称列的布局，适配较小窗口和 150% 缩放。
- 登录网址栏默认覆膜锁定：第一次点击解锁，第二次点击才能编辑；避免网页账号密码输入被地址栏抢走。
- 离开网址栏、切换窗口、网页获得焦点或提交网址后重新锁定；锁定时不接收 Tab 或回车导航。
- 用户正在修改网址时，不用网页跳转地址覆盖输入。
- 提取单独应用包，不再要求只运行软件的用户携带源码和构建依赖。

## 1.3.3

### 新增

- 内嵌网页由 Qt WebEngine 改为随应用提供固定运行时的 WebView2，支持 H.264 / AAC 网页视频播放。
- 支持 `/i/broadcasts/广播ID` 已结束广播回放，自动下载 HLS 分段并无转码合并 MP4，沿用账号、名称、序号和唯一编号命名。
- 对 `/i/btoadcasts/` 提示拼写错误并给出可能的正确链接，不直接当作有效广播入队。
- 登录信息加密保留 30 天，重启自动恢复且不延长期限；服务器失效时仍需重新登录。
- 同一 Windows 会话限制单实例，防止从不同目录重复启动。

### 修复与同版本修订

- 修复长视频解析下载和旧内嵌网页不能播放的问题。
- 修复登录模式下公开广播持续解析、无法正确识别来源账号的情况；可读取官方公开回放信息，再按需要使用登录解析。
- 广播分段复用线程连接，减少重复建立连接造成的传输超时，支持完整下载并合并两小时以上回放。
- 去除解析、下载及广播分段自动重试，保留手动重试。
- 登录窗口关闭和临时浏览器资料清理由后台完成，减少主界面卡顿。
- 加强作者关联：兼容用户包装字段、缺少类型标识以及通过作者 ID 关联的名称，修复已有文字名称却显示警告的情况。

## 1.3.2

### 界面与修复

- 优化登录窗口，删除重复说明；匿名提示精简为“登录后可下载更多内容”。
- 修复深色系统主题下报告文字难以辨认的问题，并调整窗口、报告和缩放布局。
- 解析兼容 URL 参数、POST JSON 和表单中的目标推文 ID；只接收目标内容，避免混入推荐、回复等推文。
- 精简动图说明，补充“转换 GIF 需要额外时间与空间，同时受到 GIF 格式限制”与“选择后，不允许更改”。
- 删除多余悬停说明；“清除所有失败”替换原动图格式按钮。

### 同版本新增与发布修订

- 动图新增“逐个选择”，同一批次或同一推文可分别保存 MP4 / GIF；确认结果随队列保存。
- 新增退出时最小化到托盘或直接关闭的选择及记忆，版本号右侧设置可更改。
- 托盘后台继续下载并在完成后提示；有下载时直接关闭需要确认，保留计划并清理中断残留。
- 统一 EXE、窗口、任务栏、托盘和顶部的 Peror0_sama 像素图标。
- 标注制作人 Peror0_sama，加入非商业源码共享许可及第三方许可资料。
- 移除 gallery-dl 登录解析依赖，改为项目实现的官方网页数据观察解析。
- 同步锁定依赖、离线安装包、构建所需组件和校验清单，提供包含源码的迁移构建包；运行组件仍内嵌。

## 1.3.1

### 修复

- 详情栏标题只保留“详细信息”，删除 TXT 导入的冗余解释。
- 当时的“重试所选失败 / 重试全部失败 / 动图格式”三个项目排在同一行。
- 输入框和 TXT 识别没有空格或换行分隔的连续 `https://` 链接，自动分行或拆分解析，提高批量输入鲁棒性。

## 1.3.0

### 发布

- 将 1.2.1 的队列管理、作者警告、分类报告及文件打开修订更新为 1.3.0，统一版本显示与发布包。

## 1.2.1

### 新增

- 用户可选择并记住下载目录；“打开所选文件”打开文件所在目录并定位文件。
- 下载列表新增右键开始、删除计划；选中作者才显示该作者全部操作，双击快捷开始或重试。
- 完成列表新增删除记录、打开文件所在目录、用系统默认方式打开文件；作者行可打开该作者所有文件，不提供“打开所有目录”。
- 全部任务结束后可查看按失败、警告、成功分类的报告，每条推文一行。

### 修复与同版本修订

- 更改目录立即作用于之后尚未开始下载的文件，包括已有队列中的等待项，无需重启；已开始及已完成文件保留实际路径。
- 加强作者识别；名称无法确认时继续下载并在完成列表显示警告，不再仅因缺少名称拒绝下载。
- 增高详细信息栏，支持拖动分隔条和长文本换行。
- 完整应用压缩包内置校验清单，支持解压后校验文件完整性。

## 1.2.0

### 新增

- 对 X 以 MP4 提供的动图，下载时可选择保留 MP4 或转换 GIF；普通视频和图片不受影响。
- 一次点击加入队列或一次导入全部 TXT 文件定义为一个批次，批次内统一格式并只询问一次。
- 内嵌 FFmpeg 转换组件，用户无需另装。
- 新增手动清除历史；每条结束任务保留 72 小时，正在处理的任务保留。
- 同一推文的链接按 ID 去重；清除历史后不再记忆该推文，重新下载使用新唯一文件名。

## 1.1.0

### 新增与修复

- 支持 `/mediaViewer?...` 播放器链接，去除播放器路径和参数后按原推文解析。
- 同账号项目合并为“作者 → 推文 → 媒体”层级，默认折叠，解析刷新不自动展开。
- 美化顶部栏，固定主界面分区；列表和详情在各自区域滚动，避免整个界面上下滚动。
- 提供 Windows x64 压缩包及校验文件。

## 初始版本

### 新增

- Windows EXE 双击运行，左侧链接输入与 TXT 拖放 / 多文件导入，右侧进行中和已完成列表。
- 支持完整 X / Twitter 推文链接，下载其中全部图片、视频和动图；X 以 MP4 提供的动图保留 MP4。
- 按用户名、显示名称、同帖媒体序号及唯一编号命名，默认保存到 EXE 同级 `download`。
- 默认匿名下载，可选 X 登录；失败显示原因并支持重试。
- 增加网络连接测试、代理设置，运行组件随程序提供。
