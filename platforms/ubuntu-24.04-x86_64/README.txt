XDownloader 1.3.5
制作人：Peror0_sama

用途
下载 X / Twitter 推文中的图片、视频和动图，以及已结束广播的回放。
适用 Ubuntu 24.04 Desktop x86_64。运行依赖已内嵌。

运行
1. 完整解压 release\XDownloader-1.3.5-Ubuntu-24.04-x86_64.zip。
2. 安装解压后的 .deb，然后从应用菜单启动 XDownloader。
3. 粘贴完整链接，点击“加入下载队列”；也可点击或拖入多个 TXT，导入后自动排队。
4. 默认保存到 ~/.local/share/XDownloader 下的 download 文件夹。可在应用中选择其他目录，立即影响后续未开始的文件。

链接
支持普通推文、带 /mediaViewer?... 的播放器链接和 /i/broadcasts/广播ID 回放链接。
同一行连续粘贴的 https:// 链接会自动分行。TXT 支持 UTF-8、带 BOM 的 UTF-16、GB18030，单文件上限 20 MB。
如有拼写错误，应用会提示可能的正确链接。

媒体与命名
同一推文包含多个媒体时分别下载，从 1 编号。
文件名：用户名_显示名称_媒体序号_唯一编号.扩展名。
作者信息无法确认时继续下载并警告，作者名称使用默认名称。
原帖动图以 MP4 提供时，可选保留 MP4、转换 GIF 或逐个选择。
一次加入队列或一次导入全部 TXT 算一批。选择后不允许更改。
转换 GIF 需要额外时间与空间，同时受到 GIF 格式限制。
广播回放分段由程序自动下载并合并为 MP4。

队列与历史
按作者分组，默认折叠，每个计划显示进度。右键管理任务，双击未完成项目可开始或重试。
失败不会自动重试；可手动重试或“清除所有失败”。
完成项目右键可打开文件、打开所在目录或删除记录；作者行可批量打开该作者文件。
全部任务处理结束后可查看报告。
每条任务结束 72 小时后清理历史，也可主动清除；未结束任务保留。
重复推文或广播按 ID 识别为同一任务。清除记录后不再记忆该项，允许重新下载。
去重不扫描磁盘中的相同媒体；删除历史不删除已下载文件。

网络与登录
必须能访问 X 及媒体服务器；中国大陆直连可能无法使用。
可选择系统代理、手动代理或直连；应用网络设置后，可点击“测试网络”。
默认匿名；需要时点击“登录 X”，在官方页面登录后点击“使用此登录”。
网址栏默认锁定：点击一次解锁，再点击编辑；离开网址栏或提交后重新锁定。
登录信息由当前用户的系统密钥环加密并保存 30 天，重启不延长期限；服务器失效时仍需重新登录。
换电脑或系统用户需重新登录。请勿把 data 中的个人数据随源码发布。
只能下载当前账号有权访问且 X 实际返回的媒体，登录不保证所有内容可下载。
直播未结束、没有回放、不支持的加密格式、删除或不可见内容会提示原因。

关闭与恢复
首次关闭可选最小化到托盘或直接关闭，选择会记忆；版本号右侧设置可更改。
托盘模式后台继续下载，完成后提示。直接关闭有下载时会再次确认。
退出会保存未完成计划并清理正在下载的残留；下次启动恢复队列，已完成文件不重复下载。
中断的单文件从头下载。程序运行期间不允许再开第二个实例。

源码与文档
main.py、xdownloader、webview_host 为源码，tests 为测试，assets 为图标素材。

release\README.md：发布包信息。
