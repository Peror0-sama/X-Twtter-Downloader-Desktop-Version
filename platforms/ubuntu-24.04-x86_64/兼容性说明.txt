XDownloader 1.4.0 兼容性说明
制作人：Peror0_sama

本兼容版本由 AI 辅助完成，保留原版的下载、登录、队列、报告和托盘功能。
兼容修改不影响 Windows x64 原版。各平台的登录信息和数据目录独立，不应复制账号数据。
需要能够访问 X 及媒体服务器的网络。只能下载当前访问方式有权查看的内容。

第三方组件
原有 THIRD_PARTY_NOTICES.txt 保留项目历史说明；本文件列明兼容版实际替换的组件。
第三方组件继续适用各自许可证，不附加本项目的非商业限制。

运行环境
Ubuntu 24.04 Desktop x86_64，处理器需支持 SSSE3、SSE4.1、SSE4.2、POPCNT。
解压后安装 .deb：sudo apt install ./xdownloader_1.4.0_amd64.deb
安装后从应用菜单启动 XDownloader，也可运行 xdownloader。
Python、Qt、Electron、FFmpeg 已随包提供；仍使用系统的图形桌面、密钥环和基础系统库。
需要可用的 Secret Service 密钥环；Wayland 桌面通过 XWayland 显示内置网页。
托盘图标需要桌面提供 AppIndicator 支持。安装器按 Chromium 要求配置沙箱，不关闭沙箱保护。
默认数据位于 ~/.local/share/XDownloader，默认下载位于该目录的 download，可在应用内修改。
登录信息由系统密钥环保护，保存期限仍为 30 天。请勿使用 sudo 启动应用。

兼容组件
Python 3.12.3；PySide6 / Qt 6.12.0；Pillow 13.0.0。
网页组件使用 Electron 45.3.3，自带 Chromium 和媒体解码，不使用 Windows WebView2 / .NET。
Electron：MIT，https://github.com/electron/electron；Chromium 第三方许可随运行时提供。
SecretStorage 3.5.0：BSD；cryptography 50.0.2：Apache-2.0 或 BSD-3-Clause。
FFmpeg 使用 Ubuntu 24.04 提供的 6.1.1 版本，通过独立进程处理媒体，按原 GPL v2 或更新版本提供。
对应源码和发行补丁：https://launchpad.net/ubuntu/+source/ffmpeg。
